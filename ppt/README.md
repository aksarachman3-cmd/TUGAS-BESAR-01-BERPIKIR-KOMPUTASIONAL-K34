## Ringkasan Presentasi

Presentasi menjelaskan latar belakang, solusi, perancangan, demonstrasi, serta
keterbatasan dan pengembangan simulasi.

| Bagian | Topik |
|--------|-------|
| Pembuka | Judul dan identitas kelompok |
| Latar belakang | Data karhutla, dampak kesehatan, dan faktor penyebab |
| Solusi | Pengenalan **Si Jago Merah** dan sistem simulasi kebakaran hutan |
| Deskripsi program | Tampilan grid, kondisi pohon per sel, dan simulasi per tick |
| Dekomposisi | Input, menjalankan simulasi, serta visualisasi dan rekap |
| Pengenalan pola | Pola penyebaran api, kondisi pohon, waktu terbakar, dan gerak truk |
| Abstraksi–generalisasi | Penyederhanaan hutan, angin, pohon, waktu, api, dan truk |
| Flowchart | Alur utama dan alur program per tick |
| Aturan simulasi | Tabel peluang penyebaran api dan batas hangus |
| Skor bahaya | Perhitungan skor dan contoh perbandingan target |
| Algoritma truk | Greedy nearest-first, Manhattan Distance, dan tie-breaker |
| Algoritma pemadaman | Jangkauan 3×3, lama pemadaman, dan syarat pemadaman |
| Rekap | Contoh tampilan rekap akhir simulasi |
| Demo | Skenario 4 titik api dengan angin selatan berkecepatan sedang |
| Penutup | Keterbatasan, arah pengembangan, dan pesan penutup |
